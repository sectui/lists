# Cybersecurity Lists

A collection of clean, sorted wordlists for cybersecurity work.

These lists are intentionally short: they're meant for quick checks and fast
first passes on a target, not for exhaustive brute-forcing.

## Bigger lists

If you need something more complete, check out:

- [SecLists](https://github.com/danielmiessler/SecLists): the reference
  collection, covering pretty much everything
- [fuzz4bounty](https://github.com/0xPugal/fuzz4bounty): wordlists geared
  towards bug bounty fuzzing
- [Assetnote Wordlists](https://wordlists.assetnote.io/): large lists generated
  from real-world data, updated regularly
